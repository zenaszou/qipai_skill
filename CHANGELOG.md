# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-08-17

Initial public release.

- Shared local HTML interface and event bridge for Human × Agent play.
- Strict Renju, Chess, and Xiangqi rule engines.
- Generic action protocol with role-specific views and revision validation.
- One-ply candidate safety hints for Chess and Xiangqi.
- Unit, protocol, privacy-boundary, and Playwright browser tests.
